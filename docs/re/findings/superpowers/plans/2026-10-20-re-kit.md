# RE Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A command (`python3 -m mmxdemake.rekit`) that gathers one object's code, tables, helpers, data, fields and animations into four text files, plus a shared names file and a written guide, so a person or an agent can write the three RE documents; piloted on Meta Wheel F.

**Architecture:** `mips` disassembles (moved from the data folder, with tests). `codewalk` finds function ends, state tables, the reachable functions, neighbour entries, references and object fields. `rekit` resolves the object, runs the walk and writes `summary.md`, `code.txt`, `calls.txt`, `data.txt`. `catalog/helpers.json` holds names; `docs/re-guide.md` holds the procedure.

**Tech Stack:** Python 3.10 standard library only.

**Spec:** `docs/superpowers/specs/2026-10-20-re-kit-design.md`

## Global Constraints

- Standard library only. Tests: `python3 -m unittest discover -s tests`. Baseline: `Ran 343 tests`, `OK (skipped=9)`.
- Kit output goes outside the repo (default `~/mmx-data/x6/re/<name>/kit/`); `outdir.check` refuses a folder in the repo.
- Exit codes: 0 done; 1 failed check; 2 bad arguments, bad names file or refused `--out`.
- No game data in the repo. No code comments. No code copied from reference repos.
- Commit to `master`; end each message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Spec deltas (decided while planning)

- `mips.written(word)` moves the register-write rule from `animfind` (private `_written`) to `mips`, and `animfind` imports it. No behaviour change.
- `constants` keeps following a `lui` base through `addu rX, rX, rY` (the table-index idiom `lui; addu; lw lo(rX)`), so indexed state tables are found.
- Table counts per class: visual 58, misc 64, stage 32 (from the distance between the table pointers at scratchpad `+0x84`…`+0x98`, the same in intro and Yammark).

## Review Focus

1. A walk on real code may run into data and stop with `WalkError` (no `jr ra` within 4000 words). Expected: exit 1 with the function address. Task 4 runs Meta Wheel F.
2. A shared object (code in the main program) could walk deep into the engine. Named helpers stop the walk; the 400-function limit marks the rest. Task 4 notes how far the Nightmare Virus goes.
3. `self_fields` can mistake `a0` after a call for the object. It stops counting `a0` after the first call; test in Task 2.
4. Neighbour entries can belong to another object placed next in the overlay. The summary lists them as "likely"; the reader decides.
5. Animation tables from an export with several tables per type: all are listed.

REGS = ("zero", "at", "v0", "v1", "a0", "a1", "a2", "a3", "t0", "t1", "t2", "t3", "t4", "t5", "t6", "t7",

IMMEDIATE = {0x08: "addi", 0x09: "addiu", 0x0A: "slti", 0x0B: "sltiu", 0x0C: "andi", 0x0D: "ori", 0x0E: "xori",
             0x0F: "lui", 0x20: "lb", 0x21: "lh", 0x22: "lwl", 0x23: "lw", 0x24: "lbu", 0x25: "lhu", 0x26: "lwr",

SPECIAL = {0x00: "sll", 0x02: "srl", 0x03: "sra", 0x04: "sllv", 0x06: "srlv", 0x07: "srav", 0x08: "jr",
           0x09: "jalr", 0x0C: "syscall", 0x0D: "break", 0x10: "mfhi", 0x11: "mthi", 0x12: "mflo", 0x13: "mtlo",
           0x18: "mult", 0x19: "multu", 0x1A: "div", 0x1B: "divu", 0x20: "add", 0x21: "addu", 0x22: "sub",
           0x23: "subu", 0x24: "and", 0x25: "or", 0x26: "xor", 0x27: "nor", 0x2A: "slt", 0x2B: "sltu"}
REGIMM = {0: "bltz", 1: "bgez", 16: "bltzal", 17: "bgezal"}
BRANCHES = {4: "beq", 5: "bne", 6: "blez", 7: "bgtz"}
SHIFTS = ("sll", "srl", "sra")
VAR_SHIFTS = ("sllv", "srlv", "srav")
FROM_HILO = ("mfhi", "mflo")
TO_HILO = ("mthi", "mtlo")
MULDIV = ("mult", "multu", "div", "divu")
LOGICAL = ("andi", "ori", "xori")
NO_WRITE = {0x08, 0x0C, 0x0D, 0x11, 0x13, 0x18, 0x19, 0x1A, 0x1B}
OP_JAL = 3
RA = 31


def s16(x):
    return (x & 0xFFFF) - ((x & 0x8000) << 1)


def branch_target(word, pc):
    op = word >> 26
    if op in BRANCHES or (op == 1 and (word >> 16) & 31 in REGIMM):
        return (pc + 4 + s16(word) * 4) & 0xFFFFFFFF
    return None


def jump_target(word, pc):
    if word >> 26 in (2, 3):
        return ((pc + 4) & 0xF0000000) | ((word & 0x3FFFFFF) << 2)
    return None


def written(word):
    op = word >> 26
    rs, rt = (word >> 21) & 31, (word >> 16) & 31
    if op == 0:
        return None if word & 63 in NO_WRITE else (word >> 11) & 31
    if op == OP_JAL:
        return RA
    if 8 <= op <= 15 or 0x20 <= op <= 0x26:
        return rt
    if 0x10 <= op <= 0x13 and rs in (0, 2):
        return rt
    return None


def _raw(word):
    return f".word {word:#010x}"


def disassemble(word, pc):
    if word == 0:
        return "nop"
    op, rs, rt, rd = word >> 26, (word >> 21) & 31, (word >> 16) & 31, (word >> 11) & 31
    if op == 0:
        name = SPECIAL.get(word & 63)
        if name is None:
            return _raw(word)
        if name in SHIFTS:
            return f"{name} {REGS[rd]},{REGS[rt]},{(word >> 6) & 31}"
        if name == "jr":
            return f"jr {REGS[rs]}"
        if name == "jalr":
            return f"jalr {REGS[rd]},{REGS[rs]}"
        if name in FROM_HILO:
            return f"{name} {REGS[rd]}"
        if name in TO_HILO:
            return f"{name} {REGS[rs]}"
        if name in MULDIV:
            return f"{name} {REGS[rs]},{REGS[rt]}"
        if name in VAR_SHIFTS:
            return f"{name} {REGS[rd]},{REGS[rt]},{REGS[rs]}"
        if name in ("syscall", "break"):
            return name
        return f"{name} {REGS[rd]},{REGS[rs]},{REGS[rt]}"
    target = branch_target(word, pc)
    if op == 1:
        return f"{REGIMM[rt]} {REGS[rs]},{target:#x}" if target is not None else _raw(word)
    if op in (2, 3):
        return f"{'j' if op == 2 else 'jal'} {jump_target(word, pc):#x}"
    if op in (4, 5):
        return f"{BRANCHES[op]} {REGS[rs]},{REGS[rt]},{target:#x}"
    if op in (6, 7):
        return f"{BRANCHES[op]} {REGS[rs]},{target:#x}"
    if op in (0x10, 0x12):
        return f"cop{op & 3} {word:#x}"
    name = IMMEDIATE.get(op)
    if name is None:
        return _raw(word)
    imm = word & 0xFFFF
    if name == "lui":
        return f"lui {REGS[rt]},{imm:#x}"
    if name in LOGICAL:
        return f"{name} {REGS[rt]},{REGS[rs]},{imm:#x}"
    if op >= 0x20:
        return f"{name} {REGS[rt]},{s16(word)}({REGS[rs]})"
    return f"{name} {REGS[rt]},{REGS[rs]},{s16(word)}"

```python
import struct

from mmxdemake.mips import branch_target, jump_target, s16, written
from mmxdemake.savestate import ram_at

JR_RA = 0x03E00008
STACK_ADJUST = 0x27BD
OP_JAL = 3
OP_ADDIU = 9
OP_LUI = 15
FUNCT_ADDU = 0x21
FUNCT_OR = 0x25
FUNCT_JALR = 0x09
LOADS = set(range(0x20, 0x27))
STORES = set(range(0x28, 0x2F))
A0 = 4
SELF_SCAN = 16
PAIR_GAP = 5
MIN_TABLE = 2
TABLE_MAX = 64
END_LIMIT = 4000
WALK_LIMIT = 400
MARGIN = 0x400
RAM_LO, RAM_HI = 0x80000000, 0x80200000
SCRATCH_LO, SCRATCH_HI = 0x1F800000, 0x1F800400
CLASS_TABLES = (("visual", 0x84, 58), ("misc", 0x90, 64), ("stage", 0x94, 32))


class WalkError(Exception):
    pass


class Graph:
    def __init__(self, roots):
        self.roots = list(roots)
        self.functions = {}
        self.calls = {}
        self.callers = {}
        self.tables = {}
        self.leaves = set()
        self.truncated = False


def _u32(ram, addr):
    return struct.unpack("<I", ram_at(ram, addr, 4))[0]


def _inside(addr, regions):
    return any(lo <= addr < hi for lo, hi in regions)


def is_function_start(ram, addr):
    x = _u32(ram, addr)
    return bool(x >> 16 == STACK_ADJUST and x & 0x8000) or _u32(ram, addr - 8) == JR_RA


def function_end(ram, start, limit=END_LIMIT):
    far = start
    for k in range(limit):
        pc = start + 4 * k
        word = _u32(ram, pc)
        target = branch_target(word, pc)
        if target is not None:
            far = max(far, target)
        if word == JR_RA and pc >= far:
            return pc + 8
    raise WalkError(f"no end found for the function at {start:#x} within {limit} words")


def _keeps_base(word, reg):
    return (word >> 26 == 0 and word & 63 == FUNCT_ADDU and (word >> 11) & 31 == reg
            and reg in ((word >> 21) & 31, (word >> 16) & 31))


def constants(ram, start, end):
    out = []
    for pc in range(start, end, 4):
        x = _u32(ram, pc)
        if x >> 26 != OP_LUI:
            continue
        reg = (x >> 16) & 31
        for k in range(1, PAIR_GAP + 1):
            y = _u32(ram, pc + 4 * k)
            op = y >> 26
            if (y >> 21) & 31 == reg and (op == OP_ADDIU or op in LOADS or op in STORES):
                out.append((pc + 4 * k, (((x & 0xFFFF) << 16) + s16(y)) & 0xFFFFFFFF))
                break
            if written(y) == reg and not _keeps_base(y, reg):
                break
    return out


def code_tables(ram, start, end, regions):
    out = []
    for _, value in constants(ram, start, end):
        if not _inside(value, regions):
            continue
        targets = []
        while len(targets) < TABLE_MAX:
            t = _u32(ram, value + 4 * len(targets))
            if not (_inside(t, regions) and t % 4 == 0 and is_function_start(ram, t)):
                break
            targets.append(t)
        if len(targets) >= MIN_TABLE:
            out.append((value, targets))
    return out


def walk(ram, roots, expand, regions, helpers, limit=WALK_LIMIT):
    graph = Graph(roots)
    lo, hi = expand
    todo = list(roots)
    while todo:
        f = todo.pop(0)
        if f in graph.functions:
            continue
        if len(graph.functions) == limit:
            graph.truncated = True
            break
        end = function_end(ram, f)
        graph.functions[f] = end
        callees = []
        for pc in range(f, end, 4):
            t = jump_target(_u32(ram, pc), pc)
            if t is not None and not f <= t < end and t not in callees:
                callees.append(t)
        for addr, targets in code_tables(ram, f, end, regions):
            graph.tables[addr] = (f, targets)
            callees.extend(t for t in targets if t not in callees)
        graph.calls[f] = callees
        for t in callees:
            graph.callers.setdefault(t, set()).add(f)
            if t in helpers or not lo <= t < hi:
                graph.leaves.add(t)
            else:
                todo.append(t)
    return graph


def neighbours(ram, scratch, graph, expand, margin=MARGIN):
    lo, hi = expand
    first = min(graph.functions) - margin
    last = max(graph.functions.values()) + margin
    out = []
    for name, offset, count in CLASS_TABLES:
        table = struct.unpack_from("<I", scratch, offset)[0]
        for t in range(count):
            f = _u32(ram, table + 4 * t)
            if lo <= f < hi and first <= f < last and f not in graph.roots:
                out.append((name, t, f))
    return out


def references(ram, graph, regions):
    known = set(graph.functions) | set(graph.tables) | graph.leaves
    out = {}
    for f, end in graph.functions.items():
        for _, value in constants(ram, f, end):
            if value in known:
                continue
            if RAM_LO <= value < RAM_HI or SCRATCH_LO <= value < SCRATCH_HI:
                out.setdefault(value, set()).add(f)
    return {v: sorted(users) for v, users in sorted(out.items())}


def self_fields(ram, start, end):
    regs, fields, notes = {A0}, {}, {}
    a0_live = True
    for k, pc in enumerate(range(start, end, 4)):
        x = _u32(ram, pc)
        op, rs, rt = x >> 26, (x >> 21) & 31, (x >> 16) & 31
        if k < SELF_SCAN and op == 0 and x & 63 in (FUNCT_ADDU, FUNCT_OR) and rs == A0 and rt == 0:
            regs.add((x >> 11) & 31)
            continue
        if (op in LOADS or op in STORES) and rs in regs and (rs != A0 or a0_live):
            entry = fields.setdefault(s16(x), {"read": 0, "write": 0})
            entry["write" if op in STORES else "read"] += 1
            notes[pc] = s16(x)
        if op == OP_JAL or (op == 0 and x & 63 == FUNCT_JALR):
            a0_live = False
        reg = written(x)
        if reg == A0:
            a0_live = False
        elif reg in regs and k >= SELF_SCAN:
            regs.discard(reg)
    return fields, notes
```
