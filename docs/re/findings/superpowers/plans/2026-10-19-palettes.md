# Palettes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Learn each stage's palette rule from its save state (VRAM plus the game's sprite draw commands), record it in `catalog/stages.json`, and draw `stage.png` and the `stage.ora` art layers in colour with `0x0000` transparent.

**Architecture:** `vram` reads and checks VRAM in a decompressed save state and finds the texture block in it. `palettes` holds pure functions: parse sprite commands from RAM, vote a camera per layout layer, learn the palette start, read a palette's colours. `learn` adds the `palettes` field; `stages` reads VRAM from the save state (SHA-1 checked) and draws through a shading function (colour or grey).

**Tech Stack:** Python 3.10 standard library only.

**Spec:** `docs/superpowers/specs/2026-10-19-palettes-design.md`

## Global Constraints

- Python 3.10, standard library only. Tests: `python3 -m unittest discover -s tests` from the repo root; one file: `python3 -m unittest discover -s tests -p <file>`. No `-I`.
- VRAM: decompressed offset `0x29B749`, `0x100000` bytes, 2048 bytes per row; u32 at offset − `0x408` must be 1.
- Texture block in VRAM: 4 bpp page p row r (128 bytes) at VRAM (x0 + 64p, y0 + r); x0 a multiple of 64 with x0 + 512 ≤ 1024; y0 in {0, 256}; exactly one position with all rows equal.
- Sprite commands: word 0 top byte `0x7C`–`0x7F`; word 1 = `y << 16 | x` (signed 16 bit); word 2 = `clut << 16 | v << 8 | u`; keep u, v multiples of 16, −16 < x, y < 512, clut y < 512. clut x = (`clut` & 63) × 16, y = `clut` >> 6.
- Camera vote: winner ≥ 50 votes and > 1.5 × runner-up, else `None`; layer 0 must have one.
- Rule: palette n at VRAM x = `clut_x` + (n mod 16) × 16, y = `clut_y` + n ÷ 16; ≥ 50 matches; the top candidate's share ≥ 0.95; every palette used by the stage inside VRAM (16 colours for 4 bpp, 256 for 8 bpp).
- Catalog field: `"palettes": {"clut_x", "clut_y", "matches", "agree", "cameras"}`; `agree` rounded to 3 decimals; `cameras` = list of `[x, y]` or `null`.
- Colour: `psxcolor.to_rgba` (5 → 8 bit; `0x0000` → alpha 0). Alpha 0 is not drawn.
- Exit codes: 0 ok; 1 failed check (including missing save state or SHA-1 mismatch in `stages`); 2 bad arguments or malformed catalog.
- No game data in the repo. No code comments. No code copied from reference repos.
- Commit to `master`. End each commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Yammark (or any other stage) may put VRAM, textures or palettes elsewhere. Every unknown must give a clear refusal from `learn`, never a wrong `palettes` field. Tests: Tasks 1, 3 and 4.
2. RAM holds words that look like sprite commands but are not (program code, tables). They must not swing the vote or the rule. The thresholds (votes, margin, agreement) are the guard; Task 3 tests a 10 % share of wrong palette positions.
3. `stages` on an entry whose save state was replaced or deleted must refuse with the stage name, never draw with the wrong palettes. Test: Task 5.
4. The real RAM layout has stray values in row 0 of layer 0 (it differs from the disc); values ≥ the screen count must not crash `cameras` or `learn_rule`. Guarded in `_cells` and `_tile_at`; checked by the real-data test in Task 6.
5. Older catalog entries (no `palettes`) still draw in greyscale and say `palettes not learned`. Test: Task 5.

```python
import struct

VRAM_OFFSET = 0x29B749
VRAM_SIZE = 0x100000
VRAM_W = 1024
VRAM_H = 512
ROW = 2048
GPU_HEADER = 0x408
GPU_VERSION = 1
PAGES = 8
PAGE_W = 64
PAGE_ROWS = 256
PAGE_BYTES = 0x8000
TEX_ROW = 128


class VramError(Exception):
    pass


def read_vram(state):
    if len(state) < VRAM_OFFSET + VRAM_SIZE:
        raise VramError(f"save state is {len(state)} bytes, too short for VRAM at {VRAM_OFFSET:#x}")
    (version,) = struct.unpack_from("<I", state, VRAM_OFFSET - GPU_HEADER)
    if version != GPU_VERSION:
        raise VramError(f"GPU state version {version} at {VRAM_OFFSET - GPU_HEADER:#x}, expected {GPU_VERSION}")
    return bytes(state[VRAM_OFFSET:VRAM_OFFSET + VRAM_SIZE])


def _differing_rows(vram, block, x0, y0):
    bad = 0
    for p in range(PAGES):
        for r in range(PAGE_ROWS):
            o = (y0 + r) * ROW + (x0 + p * PAGE_W) * 2
            s = p * PAGE_BYTES + r * TEX_ROW
            if vram[o:o + TEX_ROW] != block[s:s + TEX_ROW]:
                bad += 1
    return bad


def find_textures(vram, block):
    scores = {(x0, y0): _differing_rows(vram, block, x0, y0)
              for y0 in (0, VRAM_H - PAGE_ROWS) for x0 in range(0, VRAM_W - PAGES * PAGE_W + 1, PAGE_W)}
    hits = [pos for pos, bad in scores.items() if bad == 0]
    if len(hits) != 1:
        (x, y), bad = min(scores.items(), key=lambda kv: (kv[1], kv[0][1], kv[0][0]))
        raise VramError(f"texture block found at {len(hits)} VRAM positions; need exactly 1 "
                        f"(closest: ({x}, {y}) with {bad} differing rows)")
    return hits[0]
```

```python
import struct
from collections import Counter, defaultdict

from mmxdemake.psxcolor import to_rgba
from mmxdemake.stagemap import SIDE, tile
from mmxdemake.texture import TILE, bits, tile_ref

SPRITE_CMDS = range(0x7C, 0x80)
MIN_VOTES = 50
VOTE_MARGIN = 1.5
MIN_MATCHES = 50
MIN_AGREE = 0.95
SCREEN_PX = SIDE * TILE
SCREEN_LIMIT = 512
VRAM_W = 1024
VRAM_H = 512
ROW = 2048
LAYERS = 3


class PaletteError(Exception):
    pass


def _signed(v):
    return v - 0x10000 if v >= 0x8000 else v


def sprites(ram):
    words = struct.unpack_from(f"<{len(ram) // 4}I", ram)
    out = []
    for i in range(len(words) - 2):
        if words[i] >> 24 not in SPRITE_CMDS:
            continue
        pos, tex = words[i + 1], words[i + 2]
        sx, sy = _signed(pos & 0xFFFF), _signed(pos >> 16)
        u, v, clut = tex & 0xFF, (tex >> 8) & 0xFF, tex >> 16
        clx, cly = (clut & 63) * 16, clut >> 6
        if u % TILE or v % TILE or cly >= VRAM_H:
            continue
        if not (-TILE < sx < SCREEN_LIMIT and -TILE < sy < SCREEN_LIMIT):
            continue
        out.append((sx, sy, u // TILE, v // TILE, clx, cly))
    return out


def layers_from(flat, w, h):
    return [[[flat[l * w * h + y * w + x] for x in range(w)] for y in range(h)] for l in range(LAYERS)]


def _cells(layout, w, h, screens, info):
    cells = defaultdict(list)
    for y in range(h):
        for x in range(w):
            s = layout[y][x]
            if not s or s >= len(screens):
                continue
            for k, v in enumerate(screens[s]):
                t = tile(v)
                if t and t < len(info):
                    r = tile_ref(info[t])
                    cells[(r.cx, r.cy)].append((x * SCREEN_PX + (k % SIDE) * TILE, y * SCREEN_PX + (k // SIDE) * TILE))
    return cells


def _tile_at(layout, w, h, screens, px, py):
    if px % TILE or py % TILE or not (0 <= px < w * SCREEN_PX and 0 <= py < h * SCREEN_PX):
        return 0
    s = layout[py // SCREEN_PX][px // SCREEN_PX]
    if not s or s >= len(screens):
        return 0
    return tile(screens[s][(py % SCREEN_PX) // TILE * SIDE + (px % SCREEN_PX) // TILE])


def cameras(sp, layers, w, h, screens, info):
    result = []
    for layout in layers:
        cells = _cells(layout, w, h, screens, info)
        votes = Counter()
        for sx, sy, cu, cv, _, _ in sp:
            for px, py in cells.get((cu, cv), ()):
                votes[(px - sx, py - sy)] += 1
        top = votes.most_common(2)
        ok = bool(top) and top[0][1] >= MIN_VOTES and (len(top) == 1 or top[0][1] > VOTE_MARGIN * top[1][1])
        result.append(top[0][0] if ok else None)
    if result[0] is None:
        raise PaletteError("no camera for layout layer 0: the draw commands do not match the stage")
    return result


def _used(layers, screens, info):
    used = set()
    for layout in layers:
        for row in layout:
            for s in row:
                if not s or s >= len(screens):
                    continue
                for v in screens[s]:
                    t = tile(v)
                    if t and t < len(info):
                        r = tile_ref(info[t])
                        depth = bits(r.page)
                        if depth:
                            used.add((r.palette, depth))
    return sorted(used)


def learn_rule(sp, cams, layers, w, h, screens, info):
    cands = Counter()
    for sx, sy, cu, cv, clx, cly in sp:
        for layer, cam in enumerate(cams):
            if cam is None:
                continue
            t = _tile_at(layers[layer], w, h, screens, cam[0] + sx, cam[1] + sy)
            if not t or t >= len(info):
                continue
            r = tile_ref(info[t])
            if (r.cx, r.cy) == (cu, cv):
                cands[(clx - (r.palette % 16) * 16, cly - r.palette // 16)] += 1
                break
    n = sum(cands.values())
    if n < MIN_MATCHES:
        raise PaletteError(f"{n} sprites match a stage tile; need at least {MIN_MATCHES}")
    (bx, by), top = cands.most_common(1)[0]
    agree = top / n
    if agree < MIN_AGREE:
        raise PaletteError(f"palette start ({bx}, {by}) agrees for {agree:.2f} of {n} matched tiles; "
                           f"need {MIN_AGREE}")
    for pal, depth in _used(layers, screens, info):
        width = 16 if depth == 4 else 256
        x, y = bx + (pal % 16) * 16, by + pal // 16
        if x < 0 or y < 0 or x + width > VRAM_W or y >= VRAM_H:
            raise PaletteError(f"palette {pal} ({depth} bpp) would be at VRAM ({x}, {y}), outside VRAM")
    return {"clut_x": bx, "clut_y": by, "matches": n, "agree": round(agree, 3),
            "cameras": [list(c) if c is not None else None for c in cams]}


def palette(vram, rule, n, count):
    o = (rule["clut_y"] + n // 16) * ROW + (rule["clut_x"] + (n % 16) * 16) * 2
    return [to_rgba(c) for c in struct.unpack_from(f"<{count}H", vram, o)]
```
