# Custom changes

This file lists the changes that make the game different from X6 on purpose. They are design
choices of the user, not guesses. A guess or a gap goes in `docs/gaps.md`. Do not change these
back to the X6 behaviour without asking the user.

The values are in `game/CustomChanges.java` unless the entry names another place.

## Level goals

| Change | X6 | Here | Where |
|---|---|---|---|
| Level goals | X6 ends a stage only in object code. The intro ends on `game.exit_req = 0x40` after the High Max scene | A level can have a `goals` object layer. A `Goal` object has a rectangle, `mode` (`all` or `any`), `ends_stage` (bool) and an optional `goal` (the parent goal). A record can have `goal` (it is a member of that goal) and `opened_by` (a `BossGate` opens only when that goal is done). A member record is done when its enemy is killed (a despawn does not count) or, for a boss, when its end sequence finishes. A goal is done when all (`all`) or one (`any`) of its members are done; a goal with no members is never done. When a goal with `ends_stage` is done, the stage clears. In the intro, the goal of the D-1000 room ends the stage. A boss that is not a goal member in a level that has goals does not end the stage; in a level with no goals it ends the stage as before | `game/Goals.java`, `game/GoalMember.java`, `level/GoalDef.java`, `TmxLoader`, `LevelValidator` rules `goal-*` |

## User levels

| Change | X6 | Here | Where |
|---|---|---|---|
| `-Dmmx.level=PATH` | The game has only its built-in stages | The game plays a level file in the X6 TMX profile. `StageLoader.file` validates it first. A file that cannot be read gets the reject `read`, and a loader failure after the validator gets the reject `load`. A rejected file shows `LevelErrorScreen` ("LEVEL REJECTED" and a `code: message` line for each reason); any key closes the game. The status and each finding (except repairs) go to stderr, one line each. ESC in the level closes the game. After STAGE CLEAR, the next key press closes the game. Progress (lives, souls, Reploids, parts) is a new object and is not kept | `X6Game.startLevelFile`, `screen/LevelErrorScreen.java`, `stage/StageLoader.java` |
